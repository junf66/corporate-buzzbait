# 依頼内容

`./handoff/` フォルダにある静的Webサイトを GitHub にリポジトリを作って push し、
Cloudflare Pages（または Vercel / Netlify、推奨を提案してください）にデプロイ、
独自ドメインに紐付けたい。

# プロジェクト概要

- 株式会社バズベイト（buzzbait, inc.）の公式サイトリニューアル
- 銀座のWebマーケティング会社
- キャッチコピー: 「ニッチでNo.1。」
- 既に静的HTMLとして完成済み。修正は最小限で、デプロイ作業がメイン。

# ファイル構成

handoff/
├── index.html           ← 本体（外部CSS/画像参照あり）
├── styles.css           ← スタイル
├── assets/
│   ├── favicon.png      ← ナビロゴ＆ファビコン
│   └── water-main.jpg   ← ヒーロー背景の水面画像
└── buzzbait_standalone.html  ← 全部インライン化した単一HTML（参考）

通常は index.html / styles.css / assets/ の構成でデプロイしてください。
buzzbait_standalone.html は使わなくてOK（バックアップ用）。

# やってほしい作業

1. 現状の HTML/CSS をざっと確認し、明らかな修正点があれば直す
   - <link rel="icon"> が未設定なら assets/favicon.png を指定
   - <meta name="description"> 等の SEO メタタグを補完
   - OGP（og:image, og:title, og:description）追加
   - 必要なら robots.txt / sitemap.xml も生成

2. GitHub リポジトリ作成
   - リポジトリ名: `buzzbait-site`（visibility は私に確認）
   - .gitignore（最低限）を追加
   - README.md（簡素なもの: サイト名・デプロイ先・ローカル確認方法）を追加
   - 初回コミットして push

3. デプロイ
   - 推奨は Cloudflare Pages（無料・SSL自動・国内CDN速い）
   - 私が普段ログインしている環境を確認しつつ進めてください
   - GitHub 連携で自動デプロイになるよう設定

4. 独自ドメイン紐付け
   - ドメイン名は私に確認してください
   - DNS レコードの設定手順を教えてください（私が登録会社で操作する場合）
   - もし Cloudflare で DNS まで管理しているなら自動でOK

5. 動作確認
   - ヒーローの水面動画（WebGL）が動くか
   - ナビゲーション、各セクションのスクロール
   - お問い合わせフォーム（現在はダミー送信。メール送信機能が必要なら別途相談）
   - レスポンシブ表示

# 補足

- お問い合わせフォームは現在クライアント側のみのダミー実装です。
  実運用で送信機能が必要な場合は、Cloudflare Pages Functions または
  Formspree / Resend などのサービス利用を提案してください。

- WebGLで水面シェーダーを描いているため、対応していないブラウザでは
  フォールバック画像（assets/water-main.jpg）が見える設計です。

- 配色テーマ・ライト/ダークモード切替の Tweaks パネル機能は
  デザイン検討用の機能なので、本番では非表示でOK
  （body 直下の Tweaks ボタン部分を削除可）。
  ※ ただし残しておいても見た目には出ません（toggleでのみ表示）。
